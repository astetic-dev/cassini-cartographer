# 03 post - write the station post

One job: write the week's post for the station site.

## Inputs

| Source | File/Location | Section/Scope | Why |
|---|---|---|---|
| Working | `../01-tally/output/week-<nn>-tally.md` | Full file | the counts |
| Reference | `../../references/house-voice.md` | Full file | how the post reads |

## Process

1. Read the tally.
2. Open with the bird of the week, not with the week.
3. Give every count as a figure.
4. Name the ringers who were on the nets.

## Outputs

| Artifact | Location | Format |
|---|---|---|
| Station post | `output/2026-w<nn>-post.md` | markdown |

## Human check

The warden reads the post before it goes up.
